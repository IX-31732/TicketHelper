本项目是一个基于SpringAI构建的智能购票助手系统，通过AI模型实现智能节目推荐、购票规则问答、运维故障排查等功能，旨在提升用户购票体验与运维效率，减轻人工客服与运维压力。
技术栈：Spring Boot 3、Spring AI、Vue 3、RAG、Function Call、MCP Protocol、SSE、Elasticsearch、Prometheus、VectorStore、MyBatis-Plus、MySQL
技术要点：
⚫ 深度集成SpringAI框架，实现多模型适配，支持灵活切换与统一调用。
⚫ 基于RAG架构结合向量数据库，构建智能知识库，实现购票规则、退票政策等文档的精准问答。
⚫ 运用Function Calling机制，实现AI与传统业务系统的高效交互，完成节目查询、订单生成等实际业务操作。
⚫ 设计并实现MCP模型，优化AI与外部工具、数据源的连接与上下文管理，提升响应准确性。
⚫ 自定义Advisor实现高级对话引导与业务逻辑控制，确保AI交互符合购票业务流程与规范。
⚫ 实现文档内容的智能抓取与分析，自动构建向量化知识库，支持规则助手的实时更新与精准检索。
⚫ 开发智能购票助手，支持自然语言节目查询、票价咨询、座位推荐及一键下单，提升用户购票体验。
⚫ 开发运维助手，集成日志查询、链路追踪、故障分析能力，辅助运维人员快速定位与解决问题。
